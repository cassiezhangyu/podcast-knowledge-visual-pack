# E248 封面正面校准案例

## 身份

- 用户通过时间：2026-09-22
- 页面：`E248-cover-v40`
- 状态：`accepted`
- 原节目标题：从 QQ 空间到苹果设计大奖：一个非典型设计师的成长之路
- 编辑钩子：从“感觉不对”到“知道为什么”

## 文件

- `cover.png`：1200 × 1600 最终合成图；
- `cover-phone.png`：390px 手机预览；
- `cover.excalidraw`：中心内容、排版和底板的原生 Excalidraw scene；
- `official-album-mark.png`：用户要求保持原样的官方专辑品牌图。

## 为什么通过

- 原节目标题是第一视觉层级，节目名建立身份，期号不重复占位；
- 编辑钩子准确概括整期的判断形成过程；
- 中心知识图用同一问题的版本、比较、真实反馈和选择结果解释主线；
- 纯白画布与局部浅灰蓝底板形成明确视觉锚点；
- 低饱和蓝赭有稳定语义；
- 关键词、对谈者与时长补充信息但不争抢注意力；
- 手机预览仍能读出原题、钩子、中心结论和页尾信息。

## 可继承

- 信息层级；
- 白底与局部视觉锚点；
- 低饱和蓝赭配色；
- 一个内容专属中心知识图；
- 品牌、关键词、出场信息和时长的职责；
- 原图与手机图双重验收。

## 不可复制

- 所有具体坐标；
- 叠纸、圆点、选择章等 E248 专属对象；
- 标题行数、中心图步骤数量和页尾关键词数量；
- “感觉不对”“试作／比较／检验”等文案；
- `本期对谈` 标签。它必须根据节目形态改写。

## 品牌资产边界

`cover.excalidraw` 保持 `image=0`、`files=0`。`official-album-mark.png` 只在最终 PNG 导出时按原样合成；它不能成为允许位图插画、纹理或背景进入封面的先例。
