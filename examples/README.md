# 正例使用规则

> 规则本体见 `rules/visual_quality_bar.md` R20；这里是操作说明。日常对照先看各目录的 PNG 和 ANCHORS/README；`ep59-…` 是完整链路存档，gate/JSON 只在查流程细节时看。

正例教的是**判断**，不是**形式**。
- 对每个正例写出：它解决了什么问题、为什么这样选（密度、主次、阅读路线、导航任务等）。
- 再针对当前内容重新推导版式。照搬正例的布局、坐标、导航位置尺寸或模块形态 = REJECT。
- QA 中每项借鉴都用理由说明（“中心机制需要宽度，所以导航压成顶部窄带”），不得写“因为正例这样”。
- ANCHORS.md 里的坐标是该期的记录，用于理解比例与关系，不是模板。
