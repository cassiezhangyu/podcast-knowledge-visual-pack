# EP40《情绪》总览 · 质量锚点

用作 R18 的并排对照锚点。**不是版式模板**；它的配色（另一期色卡）和坐标都不照搬。

| 值得学的判断 | 为什么成立 |
|---|---|
| ② 中心是一张大的连通机制图，明显重于其他模块 | 读者先看到“情绪如何被大脑构建”的完整因果，其余模块都是在补它。 |
| 每个模块都有承载意义的图（对照、流程、状态） | 图在解释，文字只是标签；去掉文字仍能看出关系。 |
| 局部完成度高：中心对象有细节、标注贴近对象 | 细节集中在中心，形成重心；边缘模块克制。 |
| 层级靠尺度与字重，颜色只给主线和强调 | 正文不抢色，强调色在扫读时才有效。 |
| 页面没有大片空带，密度高但可扫 | 留白服务于分组，不是独立目标。 |
