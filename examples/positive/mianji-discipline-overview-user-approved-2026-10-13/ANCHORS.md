# 面基《纪律.md》总览 · Cassie 选定（2026-10-13，A-V16b）

**不是版式模板。** 下面记录的是每个选择为什么成立；下一期要按自己的内容重新推导形式（R20）。

| 选择 | 为什么成立 |
|---|---|
| ② 一张连通链：全市场 → 观察池 → 温度计 → 鱼塘＋仓位计 → 今日动作 | 本期的核心论点是“纪律把市场过滤成动作”，这本身就是一条管道；画成一张连通图，读者沿箭头就能复述方法。V13 把它拆成三个小机制，失去了“过滤”的因果，所以更弱。 |
| ② 占满整宽、分量最重 | 中心图需要横向空间放五个阶段；其余模块（①拆开、③打磨）是辅助，所以更小。 |
| 每个模块都有机制图 | ① 拆开（表达欲 \| 执行链）、③ 文档由简到繁再压回：都是状态变化，不是装饰图标。 |
| 导航拆成两块：地图在 ① 旁，提纲＋怎么读在 ③ 旁 | ① ③ 的图都窄，右侧本来就空；导航完成任务却不挤中心。位置由本页空白决定，不是固定右栏。 |
| 颜色：墨色正文与图内标签，灰色非焦点轮廓，主色给结论、模块标题、编号、主链箭头、液柱 | 蓝只标出层级和主线；模块标题用主色让三段入口一眼可扫（Cassie 在墨色标题版与主色标题版之间选了主色）。正文和轮廓不用蓝，所以不再“满页蓝”。 |
| 辅色只在“不碰”、风险提醒与出仓箭头 | 暖色只承担“不做／风险”语义，≈5% 墨迹。 |
| 手工排线 + tokens 笔触 | 排线是质感（浅 hatch），液柱和热格是信号（深色）。 |

颜色规则以 `rules/visual_quality_bar.md` R4b 为准；本页的颜色重量来自液柱、热格等实心信号块。
