# 原生手绘线条固定规则

每次出图读取本规则与 design_tokens.json → stroke.role_settings。1200×1600画布使用角色参数，其他画布整体同比例缩放。

## 笔触与校准参考

手绘线条保持对象本来的方向和几何结构，以角色参数表现自然起伏与局部复描；信息框与排版线按下文“默认画法”执行。

圆弧、环形箭头等曲线用 `curve` 角色，参数读取当前 tokens；用 4–6 个控制点并开启平滑（Excalidraw roundness type 2），不以密集折线叠加抖动。

实图校准优先打开正式正例 `../examples/positive/ep88-cover-user-confirmed-positive-2026-10-01/` 与 `../examples/positive/ep88-overview-abc-user-approved-2026-10-22/` 的物件与信息框完成度。历史笔触样稿见 `../examples/retired/ep88-p13-rough-stroke-accepted-2026-09-26/`（已停用，非强制基准）：比较对象笔触、曲线和信息框单线效果，不复制案例的对象、构图或历史参数。

## 角色
数值以design_tokens.json为唯一来源：object为较大的具体对象轮廓；object_simple为小幅、简单物件的单线轮廓；detail为对象内部部件；accent_detail为需更明显笔触的内圈、进度线等局部细节；relation为有来源且需要较强动态笔触的关系箭头；connector为抽象对象之间的简单直线连接；emphasis为批注或划除；heavy_detail为有动作含义的粗段；rule为排版分隔；surface为弱背景底板；frame为信息框及显示区域；fill_only为无描边色块。物件轮廓保持object或object_simple，不因元素类型为line而降级。纸张、衣物、镜子等允许局部自然复描；信息框不应与真实物件使用同样强的复描。

**易错分配：抽象标签框、信息框和导航框用 `frame`，不能因其画成矩形就套 `object` 的高 roughness；简单直线语义连接用 `connector`，需要明显动作感的箭头才用 `relation`。不得在单页脚本中为了消除双线而全局覆盖 token 到近乎机械直线。构图前先明确角色，scene 生成后先运行 `check_strokes.py`，角色或参数错误必须修复，再渲染实图。**

**默认画法：一条原生路径形成一条可见手绘线。** 信息框、抽象结果框、导航边界、长横线和页脚分隔线用 `frame`／`rule` 的轻微 roughness，保留笔触起伏，但在原尺寸应读成单线；若能沿边缘持续追出两条平行轮廓，就降低该线的复描感并重渲。不要通过再叠一条偏移线、同尺寸框或闭合描边副本制造手绘。具体物件的局部自然复描可保留，但不能扩散成全页双线框。所谓“单线”不是 roughness=0 的机械直线，也不是人为弯曲的光滑线。

小幅物件若因 `object` 的复描在原图里出现持续的双轮廓，改用 `object_simple` 并重渲核对；这仍是物件轮廓角色，不能用 `detail` 冒名规避检查。识别物件时先画清外形、提手或其他必要部件及装配位置，再决定填色。大块深色实心剪影若压过文字、让部件糊成一团，优先换成同系列浅底与单线轮廓。仅在实物识别和信息主次都因此更清楚时使用实心填充。按共同质量判据检查原图与390px的完整图文；遮标签仅作诊断，不因必要名称参与识别而拒绝。画面保留自然笔触，不能退化成机械图标。

长曲线控制点、路径长度与椭圆尺寸的组合风险在受检导出前由 `audit_scene_layout.py` 诊断，详见 `render_diagnostics.md`。参数合规与风险阈值均不能代替实际单线效果；不因诊断自动降低全页 roughness 或改写物件角色。

## 执行与检查
- 保留点列、seed、真实曲线、闭合轮廓和部件接触；不追加波浪控制点、平移重描副本或随机噪声。圆弧来自对象本身。
- 共用边只绘制一次，避免相邻矩形叠线。拆边时保留填充与对象身份；按边角色声明参数。
- 同一信息框含浅底或表头时，先绘无描边底板与局部填充，再用一个 `frame` 图元绘外轮廓；不要让后画的填充压淡某一边。原图和灰度图都要比较同一外框的上、下、左、右边：角色参数相同仍可能因叠放顺序产生可见的颜色或粗细差异。
- 用户已通过的局部样稿优先作为本包校准，参数更高不等于手绘感更好。
- 运行python3 scripts/check_strokes.py <scene或目录>；角色合规后真实导出全尺寸、390px和灰度。参数合规不证明单线和手绘感同时成立；若原图出现平行双线，先检查是否将抽象框错分为 `object` 或将简单连接错分为 `relation`；若原图像机械直线，检查是否私自把 roughness 调得过低。修正后再次运行角色检查与实图审查。逐项检查信息框、长横线、导航边界和页脚：在原尺寸读成一条有笔触的线，局部放大也没有第二条完整平行描边；再检查插图自然、无穿字/断裂/错误连接。机器检查不能替代实际图片或作者自检。
- 修改只影响获准范围，冻结内容、布局和文字；需要改布局时说明具体碰撞证据，禁止借笔触返工重做已认可构图。
