# 内页模块合同：内容地图与当页定位

适用于本材料包 P01 总览及后续所有 Deep Dive 内页；封面执行封面协议。此合同固定**信息职责与视觉层级**；本期明确锁定的几何位置另由当前页面合同记录。新系列保留身份、整页判断、主内容、辅助地图／提纲与来源，不默认继承正文分区、右栏或底部导航的位置。正文内部的图形、栏数、对象和关系由每页内容决定；调整位置仍保留全部职责，不能默默删去导航或来源。

## 全页官方专辑封面合同

封面、总览、总览续页和所有深度解读页右上角均显示对应播客专辑的官方封面。默认1200×1600画布使用 `design_tokens.json → cover.brand_asset.box`：位置(976,64)，尺寸144×144，右边距80；同包各页保持一致。期号或节目名相似不能作为换用其他专辑图的依据，例如番外使用番外的官方封面。

创作前核对官方来源和当前使用范围，保存官方原图与SHA-256。缺少可靠素材时记录阻断，不静默省略或仿绘。封面保留原色、等比例、完整图形；它是节目身份，不承担知识解释，也不决定正文构图。标题区域为其预留空间，长标题优先换行或重排，不用封面遮盖文字或缩小字号。

新 `construction_spec.json` 必须声明 `album_art_policy: "all_pages"`，每页 `brand_asset` 填同一素材路径、SHA-256及上述位置尺寸；素材保存在本期工作区内。正文scene继续保持image=0、files为空，专辑封面仅在最终导出时受控合成；原图合成后再生成手机和灰度预览。审核输入携带官方资产及合成绑定，实际检查各页身份、尺寸、长标题避让和手机效果；素材文件随交付包提供，原生正文源文件不声称包含这层位图。合成前必须核对：素材来自 `episode_metadata.episode.podcast_cover_url`（专辑/播客封面），不是 `episode_cover_url`/`cover_url`（单集封面）；`brand_asset.source_url` 须与之逐字一致，否则渲染器拒绝。旧规格和已验收图保留原审批，新制作不借兼容旧规格省略全页封面。

## 1. 页面分区

1200×1600 画布沿用 x=80 / x=1120 安全线及 `design_tokens.json` 的字号角色。先按当前内容安排主解释与支撑，再在获批的可变范围内安置辅助导航和来源。P01 的左正文／右导航及 x=80–883／x=911–1120 是已校准系列的具体示例：当前合同明确锁定时才复用其主辅位置；已有导航换位授权时按当页阅读路径决定。画布、字级及明确锁定的页眉页脚不决定正文应有几层、几栏或何种入口。

本包校准时明确哪些职责与几何位置固定、哪些可以随内容变化。用户锁定标题区域时，页眉、主标题、副标题、分隔线和核心结论按获批位置与字级保留，页面文案仍随内容变化；正文的重心、栏数与阅读路径由内容决定，不逐页套用相同的上中下分区。新页面在图片内容规划中说明导航职责、位置可变范围及理由，规划获批后在该范围内自主安排，不逐次请求换位确认；已获批页面明确锁定的位置继续按原合同执行。内容地图与本页提纲移动后仍须保持辅助权重、完整信息及与正文入口的对应关系。下文右栏坐标属于默认校准，不覆盖本包另行获批的位置合同；授权与实际位置记入本包记录，不复制为其他系列的默认坐标。

位置合同变化后，照实记录既有检查器的适用范围与结果；额外核对职责和对应关系不能冒充原检查通过。正式交付仍须满足其门禁，不以导航换位授权免除审核。

### 导航位置与表现形式

仅交付一张总览且地图与提纲职责实际重合时，可以合并重复条目；保留节目级结构、当前页入口与必要关系说明，不固定放在页底。实际区域写入当前合同及区域检查输入。

页面合同允许导航变化时，先完成正文主解释结构，再按阅读路径、空白和主辅权重安排地图与提纲；可采用左侧索引、右侧开放目录、底部书签或局部边缘标记。跨页保持主题顺序、页段、当前标记及正文对应，位置和表现形式可变，不为凑变化机械轮换。

整包内容地图与本页提纲共同组成辅助导航，区域区分要求须同时覆盖两者。可用共同的高明度浅色背景、克制的边框线、边缘带或有明确归属的分隔建立导航区；若两者分置，也须各有可辨的区域归属和一致的导航视觉标识，不能只为整包地图加底色或边界而把本页提纲留在正文文字轨道中。再用字号、缩进、短刻度、页签和留白组织条目。开放索引也要让读者迅速辨认两部分导航的范围；不要求每页采用同样的整块色底或边框形状。背景与边线应弱于主内容，对象及文字留足内边距，完整导航区与相邻正文保持缓冲；装饰不得暗示知识因果。

导航区域可辨之后，还须组织其内部信息：每个页段与主题构成紧密的条目，条目之间使用一致节奏；全文地图与本页提纲有清楚的层级或分隔，提纲序号贴近名称并对应正文入口，当前主题有易定位的克制强调。浅底或边框只能说明区域归属，不能代替条目绑定与阅读层级。按实际宽度选择单行、双行、缩进或分组，不将松散文字平均撒满导航区，也不固定条目框、位置或栏数。

保留当前合同锁定的标题、副标题、截图区域与来源页脚，逐图检查导航换位或区域区分没有挤压正文、降低字号或改变读取顺序。已有认可页的局部修改仍执行其授权范围。

| 模块 | 放什么 | 阅读职责与权重 |
| --- | --- | --- |
| 页眉 | 专辑名 + 当前页面类型（知识总览／深度解读） | 低权重身份标识；不以专辑名冒充具体单集 |
| 标题区 | 本页主标题、限定范围的副标题、其后的分隔线 | 先说读者要理解什么，再明确讨论范围 |
| 核心结论 | 一句或两行陈述式整页判断 | 高于模块标题；内容必须与图上关系一致 |
| 主内容 | 内容驱动的对象、动作、状态、逻辑连接与必要文字 | 解释本页问题；模块数量及构图不预设 |
| 整包内容地图 | 已批准的主题顺序 + 对应页段 + 当前主题标记；只写面向读者的节目内容结构 | 辅助定位；位置按当前合同，不决定正文骨架；不得出现生产范围、暂缓、未出页等制作元数据 |
| 本页提纲 | 本页可定位的内容入口，序号与主内容对应 | 查找内容；不把章节编号变成等宽横带 |
| 页脚左 | `节目：《官方完整单集标题》`；下一行 `回听：本页相关时段` | 离开封面后仍能找到具体单集与相应音频；总览可写整期 |
| 页脚右 | `第XX页 / 共YY页` | 准确页码；与内容地图的主题进度各司其职 |

## 2. 辅助导航更新规则

1. 整包地图读取当前获批《内容拆分》与页面清单，写**主题和对应页段**；总页数或拆页变更时，整包每页地图、页脚分母同步更新。当前页所在主题以一处克制的标记强调；地图文本和底色保持辅助层级。
2. 本页提纲从当前 Page Content Pack 提炼实际阅读入口，使用清楚、一致、可定位的序号或标记；主内容相应模块用同一序号建立定位。序号仅表示查找次序，不自动声称时间或因果顺序。
   显示样式按版面选择，可用普通数字、括号、角标、字母或有明确对应的其他标记，不固定圈①圈②；同页同级保持一致，不为变化而混用。检查器直接识别独立数字、圈号及带分隔符的数字前缀；其他样式在实际文字元素的 `customData.navigation_number` 写对应的正整数逻辑编号。标题与标记合为一个文字元素时另填 `customData.navigation_label` 为真实可见标题，检查器核该字符串确实出现在文字中；单独标记仍核邻近真实标题。图形徽标可配可见文字标记，不以隐藏文字补签。逻辑编号只供对应校验，不增加成品伪事实或改变显示样式；审核仍看实际标记、标题与归属。
   构图前逐项写出「提纲编号与短语 → 正文同号入口与标题」映射；提纲条数由本页真正独立的内容入口决定，从属案例留在所属入口内，不为凑足三个序号把它升格成同级板块。正文可采用不同大小、位置和图形结构，不为凑序号切成等权板块。真实渲染后运行 `python3 scripts/check_outline_body_alignment.py <当前内页.excalidraw> --regions auto`（v0.4.5-local：区域默认从 scene 自动推导——提纲区＝包住“本页提纲”的最小框，正文区＝其余主体；`render:scene:checked` 不传 `--outline-regions` 即自动推导并保存 `outline_regions.auto.json`）。只有自动推导确实不适用时才手写区域文件，且须含 `manual_reason`（为什么不能自动）和 `overlay_screenshot`（区域叠在原图上的截图，相对区域文件路径），否则渲染器拒绝；不得为通过检查而改区域。旧用法：获批导航换位时加 `--regions <实际区域.json>`，其中 `body_regions` 与 `outline_regions` 分别列出正文入口和本页提纲所在区域的 `{x,y,width,height}`，不用整包地图区代替提纲。再对照原图和390px逐项核验同号内容确实回答同一提纲项。缺号、重号、同号错题均不得输出前检查；同一主入口只出现一个导航编号，返回提示可用文字定位。机器只核验当前区域中的编号、附近标题及同级角色/字号一致，不证明语义职责正确；实际区域与获批位置须由创作者核对。
3. 提纲内部若有并列、主从、例证或“相关但独立”的关系，用括组、间距或简短说明表达；关系以来源台账为准。没有来源支持的连接不因统一导航样式而补画。
4. 导航区无论在侧边或底部，都使用本期配色浅阶、可辨的辅助文字与适度浅底／弱边界同正文分开。检查整页缩略图时，读者应先看标题、结论和主内容，再看地图与提纲；导航区不能成为最强色块或最大标题。
5. 本页提纲的条数由内容决定。若当前内容撑不满或塞不下主内容区，先检查页面职责、合并与拆分，再调整正文构图；不能把正文事实缩成导航小字。
6. 导航区的关系说明可压缩重复词，但须保留并列、因果、先后及适用范围等决定读法的限定。外围锚点用于统一视觉节奏，不能为了凑齐通过版的行数，把“相关但独立”改写成“下一步”，或删掉关键的否定条件；必要时增行并检查与页脚的真实距离。

## 3. 同一材料包的外围模块校准

开始下一张内页前，读取本包通过的总览原图，核对身份、字级、配色和来源职责；只对当前合同明确锁定的外围位置比较几何基准。正文和已授权可变导航按本页内容重新组织，不能把总览布局作为空白模板。输出前检查前比较同一职责的字号、字重、行距与页码对齐，再对照真实 PNG；按 visual_reasoning 的构图审查确认外围没有决定正文骨架。

以下仅为「面基」已获批 P01 的1200×1600外围校准示例（单位 px），不是当前任务的默认合同。只有当前包明确采用这些锚点时，才执行下表及其几何比对；其他包从各自已通过总览提取相同职责的锚点，确认后记录当前合同，不继承示例的颜色或节目文字。

| 模块 | 本包固定锚点与层级 |
| --- | --- |
| 页眉 | 色条 `(80,62)`、专辑／页型文字 `(80,88)`，`header_meta 22`；页面类型只换词，不移行或缩字。 |
| 右栏底板 | `(911,370,209,1090)`，左界线从 `(911,380)` 至 `y=1459`；右栏文字左锚点 `x=930`，提纲内容 `x=970`。 |
| 地图 | 标题 `(930,384)`、`subheading 26` 且与 P01 同字重；首项页段／主题 `y=430/458`，第二项 `y=510/538`，后续每项加 `70`。当前主题标记贴近对应行，尺寸与底色沿用通过版。 |
| 提纲 | 分隔线 `y=943`，标题 `(930,965)`、`subheading 26` 且与地图标题同字重；序号圆直径 `32`，首项圆 `(930,1015)`，后续每项加 `64`；数字 `annotation 22` 居中，文字 `diagram_label 24` 从 `(970,1017)` 起。条数少时保持间距，关系说明在下方独立成组。 |
| 页脚 | 分隔线 `y=1490`；左侧双行文字起点 `(80,1506)`、`footer_meta 22`、行高 `1.3`，首行具体单集，次行本页回听；右侧页码框 `(930,1512,190)`、`footer_meta 22`、右对齐。不得因单集标题长短改用更小字号或把页码改为左对齐。 |

若本页标题、提纲条数或来源长度与这些锚点真实相撞，先调整正文空间或提出本包统一的外围修订，并同步检查全部已出内页；不允许单页悄悄漂移。每次局部修正保存通过版和待修版的 scene／PNG 哈希，限定可改区域，并复核正文元素未变。

当前包采用上述外围几何合同且检查器适用时，scene 完成后运行 `python3 scripts/check_inner_page_chrome.py <本包已通过总览.excalidraw> <当前内页.excalidraw>`；失败时修正对应职责元素后重新渲染。机器比对只检外围锚点与角色，仍须并排看两张真实原图及手机图，确认没有字形碰撞、页脚挤边或右栏抢正文。

## 4. 页脚与真实渲染

页脚预留双行 22px 来源文字及独立页码区域。完整单集标题使用《》，回听范围按 `rules/footer_source_ranges.md` 核对时段。页面按真实标题宽度与内容高度计算，不逐页缩字。渲染全尺寸和 390px 后检查标题末字、两行页脚、分隔线、页码与 x=80 / x=1120 安全线的实际字形距离；只看 scene 坐标或静态字号检查不算完成。

正向校准见 `../examples/positive/mianji-p01-overview-user-approved-2026-09-29/`。借用模块合同与阅读权重，不复制本期蓝色值、三栏观察窗或具体文本。

## 地图只面向读者

`production_scope` 与 `deferred_out_of_scope` 只是工作产物里的制作状态，永远不出现在成图上。成图（含整包内容地图、本页提纲、页脚）不得写“本轮范围／只做总览／暂缓／未出页／范围外”等字样，也不得列出“暂缓的深读主题”。生产范围缩小时（如只做总览），整包内容地图只呈现本期节目面向读者的内容结构（模块主题顺序 + 已出页的页段与当前标记），不暗示还有未制作的页面。交付前运行 `python3 scripts/check_reader_facing_text.py <scene.excalidraw>`，必须通过。
