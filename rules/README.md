# rules/ 导读：先看哪几份

**第一次用，按这个顺序读：**
1. `main_workflow_sop.md`：唯一的总流程（7 个确认点、SOP A/B/C、必跑检查、交付）。
2. `visual_quality_bar.md`：质量底线 R1–R21。颜色只看 R4b，正例用法只看 R20，陌生读者检查看 R21。
3. 要画哪类页，就读哪份：`overview_page_production.md`（总览）、`cover_page_production.md`（封面）、`deep_dive_page_production.md`（深度页）。
4. 作图时随手查：`handdrawn_strokes.md`（线条）、`typography_hierarchy.md`（字号）、`cjk_glyphs.md`（简体字形）、`inner_page_module_contract.md`（页眉页脚和导航）。

**到了对应阶段再读：**
- 转写：`transcription_guide.md`、`audio_pipeline.md`
- 内容：`content_pipeline.md`、`page_content_planning.md`
- 视觉推理与审核：`visual_reasoning.md`、`visual_creation_context.md`、`page_visual_production.md`、`independent_visual_review.md`、`design_gates.md`、`acceptance_case_index.md`
- 精修、交付、文案：`visual_pack_execution.md`、`public_copy_production.md`、`footer_source_ranges.md`
- 各阶段完整条文：`phase_details.md`（从 SKILL.md 移来）

**正例（`examples/positive/`）怎么看：** 先看每个目录里的 PNG 和 `ANCHORS.md`/`README.md`（写的是“为什么这样选”），不要照搬形式（R20）。`ep59-…` 是完整制作链路的存档，里面的 gate/JSON 文件只在要查流程细节时看，日常对照只看 `delivery/*.png`。
