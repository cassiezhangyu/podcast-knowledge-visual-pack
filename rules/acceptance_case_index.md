# 已验收案例索引

新页面、主结构重构或相关故障处理时读取本索引。先按理解任务选择参考；下表的复盘全文只在命中相应问题时读取。

## 参考选择与解读

1. **本次用户指定参考：**优先实际查看用户提供的正反案例，用于校准解释价值、审美完成度与失败边界。用户只指定笔触或字体用途的参考，按该职责使用。将当前资产位置与哈希保存在项目预检中；公共 Skill 不依赖某台机器上的私有素材路径。
2. **同系列已认可页面：**校准已批准的外围模块、字级、配色职责和完成度；同时核对认可范围，局部通过或限质选择不自动升级为整页 TARGET。正文继续由本页内容决定。
3. **内置案例：**按当前理解困难或下表故障补充对照；用户本次有明确参考时，内置案例不能替代它。当前内容、选定配色和规范仍决定事实与参数，不从历史图片复制。

选取能帮助当前任务的参考，逐图指出：它解决哪种理解困难；哪个部件、状态或空间差异承担关键解释；文字贴在哪里、指认什么；本页应迁移哪种解释方法；另指出画面焦点、局部完成度、文字贴合与阅读节奏，并写出实际绘制决定。将这些具体观察和本页影响写入现有 `references` 记录。只写“主次清楚”“手绘自然”还不足以指导绘制。

学习参考时保留方法与完成度，重新选择本页载体、比例和阅读结构；方框、流程、纸张或大图是否有效由它承担的解释职责决定。参考中的事实、人物与场景不成为本页来源。

各页既有基准继续查看：Overview 直接打开 `examples/positive/e248-overview-accepted-2026-10-07/overview.png` 和本页相关反例；Cover 打开 `examples/positive/e248-cover-accepted-2026-09-22/cover.png`；Deep Dive 按问题选已通过内页与相应反例。下表命中的补充案例按其原图和手机图核对。基准图不替代本次用户指定参考。
