# 对外文案生产协议

适用于页面中的正式公开文字和小红书配套文案。内容判断已经在《内容梳理》《内容拆分》中完成；本阶段只改善表达，不新增节目结论。

## 顺序

1. 从已通过审批的《内容拆分》和页面内容包写 `xiaohongshu-draft.md`。
2. 逐句标注其来源模块、案例或边界，先完成忠实度自查。
3. 使用 Humanizer 只处理表达层：去除模板腔、强行三段式、空泛总结和不自然转折；不得改变事实、归因、论证强度或来源范围。
4. 保存处理后 `xiaohongshu.md`，再做 AI 痕迹人工检查。
5. 对比处理前后，完成忠实度回归；记录到 `public_copy_record.json` 和 `xiaohongshu-review.md`。

## 小红书文案内容

默认标题、正文及话题合计不超过800个字符；用户明确其他上限时遵从。以保存文件计数，中文标题、正文和话题均纳入，避免只估算“约多少字”。完成后写入当前交付版本；添加文案与记录后重建ZIP并核对文件hash。

- 简单介绍播客真正讨论的问题、主要内容和适合继续阅读的理由。
- 保留节目中的重要案例或具体对象，避免把全文压缩成抽象口号。
- 语气自然、克制，不模拟听众体验，不写“颠覆认知”“一定要看”等无来源营销语。
- 标题和正文不承诺节目没有回答的问题。

## 门禁

以下任一项成立时，`public_copy_gate` 必须失败：

- 《内容拆分》审批哈希失效；
- 缺少处理前或处理后文案；
- Humanizer 被用来补写内容判断；
- 忠实度回归或 AI 痕迹检查不是 `pass`；
- 记录中的文件哈希与当前文件不一致。
