# 文字层级与字号硬性标准

适用于1200×1600画布；数值唯一来源为当前已批准design_tokens.json的typography.role_sizes。下表及本规则内数值是Skill内置默认值；当前合同有已授权的参数时按该文件执行，语义角色与层级职责不变。其他画布按同一比例整体缩放。

构图前给每个文字元素在customData.typography_role声明角色。角色由内容职责决定，不由句子长短决定。同一句跨行、同组并列文字使用同角色；加粗副本继承原文字角色。重点对象名称必须是需要识别的真实对象，不得将普通正文升级以规避检查。

送审前运行：`python3 scripts/check_typography.py <scene或scene目录> --design-tokens <当前design_tokens.json>`，与正式prepare使用同一参数文件。省略参数仍使用Skill内置默认值，仅适用于当前确实采用默认参数的场景。缺失角色、角色不在参数表、字号不等于角色值、内页强层级缺少可见字重，或单行估算宽度超过文本声明宽度，均为失败。宽度估算只筛出风险，不能证明真实字形已留在边框内。正文和必要边界不得通过opacity或缩放变成小字。需要其他字号时先获得用户明确授权，记入页面合同和参数；容量不足先重分栏宽、显式换行和局部空间，不采用逐条缩字。

机器一致性检查后逐页核对真实全尺寸、390px与灰度图：按「主标题→定位副题→整页结论→模块标题→正文→右栏」逐层与正例并排检查字号、字重和颜色职责。对每个浅底区域、描边容器、右栏及页脚，查看实际末字与边界的距离；文字穿出、贴住边框、压线、跨栏或依赖缩字才能放下时，先显式换行或重分空间，修改后重渲三图。检查记录要写出高风险文字的元素 ID、实际位置与可见间距；不能只填「无溢出」。字号合规不代表审美或可读性通过。

整页核心结论按论证职责标注page_conclusion，视觉重要性必须高于模块标题；页头定位说明仍可为deep_thesis，不把所有绿色句子升级。已有加粗副本继承32px及同一角色；同级标题维持一致。带序号的内容主标题用 `section_entry` 30px、本期主色和强字重；编号圆只负责定位，标题文字本身也必须醒目。图内次级主题用 `section` 28px，正文用24px，形成可见递减。保留高密度编辑信息图，不通过放大所有字或删减证据制造空页面。

字重按阅读职责决定，不由字号大小自动推断：内页主标题、整页核心结论、一级模块标题、栏目标题及右栏「整包内容地图／本页提纲」必须明显强于正文；强层级的角色名单以 `design_tokens.json → typography.strong_inner_roles` 为准。正文、图内普通标签、边界、页眉页脚及右栏条目保持常规字重。Excalidraw 当前 sans 文字若没有原生加粗属性，使用同文、同色、同字号、横向错开约 1px 的一层重字副本；副本继承原角色，不能用改变字号或多层错位制造粗糙字边。正例 P13 和面基 P01 的标题、结论及模块入口均有这一可见处理；它是文字字重，不适用于线条复描。局部强调不得让颜色和重字反复争夺注意力。同一级标题保持同一字重。

## 颜色与视觉强弱

本期具体 HEX 仍读取已选色卡和跨页颜色职责表；这里固定的是**文字职责**，不固定其他节目的色相。主标题用最稳定的深正文色；整页结论用足够深的主色并保持强字重；带序号的内容主标题统一用本期主色，和深色正文形成明确区别。图内次级主题、栏目标题用深正文色或主色。副标题／定位说明虽然小于主标题，也必须使用深正文色或可读的主色，不能与页脚、来源、右栏条目共用弱化色。正文及必要边界用正文级对比度；辅色只标有明确语义的局部信息。右栏标题可以用辅助色，但须有上述强字重；右栏条目、页眉页脚可弱化，当前项再用主色加标记。白底、浅底和灰度图都检查对比度，不以色相差代替层级。

### 相邻标题的层级检查

1. 先按内容职责定层级，再分配字号和颜色：主标题、整页结论、带序号的模块标题、模块内小标题、正文分别承担不同扫描任务；不能只凭“这是标题”就统一上主色。
2. 相邻两级标题必须能直接分辨。上层 `section_entry` 已用主色时，其下并列的 `section` 小标题优先用深正文色，保留 28px 和强字重；让 30px 主色上层、28px 深色下层、24px 正文形成连续层级。只有实际像素证明两级仍清楚，且颜色确有语义职责时，才允许下层继续用主色。
3. 同级并列标题保持相同字号、字重和颜色；一页四个并列主题不能因色块不同就随机换色。色块背景改变时仍要检查每个标题的对比度。
4. 颜色不代替字号和字重，编号圆也不代替标题本身。若两级都很醒目，先调整相邻层级的颜色职责；若仍分不清，再检查字号、字重、间距和位置，不靠叠加装饰或缩小正文制造差异。
5. 原图、390px 和灰度图分别检查“先看到哪一级、再读哪一级”；灰度下即使失去色相，字号、字重和空间归属仍应保持阅读顺序。检查结果记录到当版自检，不能以 token 合规代替像素判断。

构图前对照已通过正例原图和 390px 图，写下主标题、整页结论、副标题、模块标题、正文、右栏标题、右栏条目各自的字号、字重、颜色职责；至少在初版渲染后再并排看一次。检查脚本负责角色、字号和强层级字重，不能替代真实像素下的颜色对比、大小关系及阅读顺序判断。若数字合规而页面仍像同一重量的文字清单，先修正色彩和字重分配，再决定是否需要重构内容布局。

**参考图校准不能只对字号表。** 同尺寸并排比较真实 PNG 时，先量出主标题、结论、一级模块、正文、右栏标题与条目的实际字面高度和相互比例，再看字重、颜色、行距、所在色块和图形墨量是否改变了它们的视觉等级。发现差距先定位是角色误标、字重不足、对比度不足、拥挤还是图形过重；只修改造成差距的层，不因“看起来偏小”而给全页字号加码。若参考图与当前 scene 的角色字号一致，应明确记录这一事实，并修复具体的视觉干扰；仍需重看原图、390px 与灰度图，不能以数值一致宣布完成。

## 七层职责校验
内页统一：主标题45、副标题25、核心结论32加粗、带序号的内容主标题30、图内次级主题28、模块副标题26、正文24、附录或备注22px。模块标题和副标题的字重按上述阅读职责判断。封面专辑名28px、节目标题62px；内页页眉页脚22px，图内短标签23px及对象名称27px作为专用语义角色保留。
不得把title下方的subtitle按坐标自动认定为核心结论；先问它是在限定本页范围，还是综合论证得到答案。页面副标题是定位/展开说明，核心结论是读者最终应带走的回答。检查页面上所有总结句，选取整页核心结论标为page_conclusion；局部例子结果保留正文或模块层级。同一视觉职责在全包同字号，不能借换角色满足机械检查。结论32px增大后应换行或局部重排，不删证据、不缩字。逐页输出七层语义台账再送审。

层级由实际内容存在性决定；某页没有独立副标题时不要补造重复句。总览的节目级主命题可承担核心结论，单个示例的路径或效果不能冒充整页结论。
