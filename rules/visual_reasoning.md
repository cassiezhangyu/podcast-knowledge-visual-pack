# 内容驱动的视觉创作

新页面和主结构重做先执行 `visual_creation_context.md`。本规则指导构图与核心验证；完整实现另读逐页协议，完整 TARGET 另由隔离审核判定。参考选择按 `acceptance_case_index.md`，质量标准按 `taste.md`。

## 1. 从本页理解任务出发

读当前批准内容，回答：读者最容易混淆什么？要比较哪些对象、条件、范围或说法？哪条关系回答页面问题？哪些事实是证据、例子或边界？没有物理机制的内容，按其判断或论证关系表达；不补造病因、动作、实际案例或数量。

写入现有 `main_visual_explanation`：读者从哪个可见差异或空间组织，理解哪条有来源的关系。具体指认承担判断的对象身份、状态差异、比较依据或范围位置，按内容选择，不必全用。`text_graphic_split` 指明图与文字各自承担什么：图让哪些对应或区别直接可见，文字补充哪些准确论点、证据与限定。图形无需创造新事实，可以降低匹配、比较、定位、追踪或阅读负担。

文稿顺序不决定成图顺序。先确定回答整页问题的核心对照，把最大的解释空间留给它；容易画的类比与引子只占其论证需要的分量。正例中的对象丰富度须与其判断职责一起迁移，不能只迁移物件数量。

重构已有认可页面时，在现有 `main_visual_explanation` 中明确本次要改善的阅读或观感、准备用哪个可见依据判断、旧版哪些优势值得保留，再选择新结构。改善可以落在比较、查找、解释或画面完成度，不要求所有维度全面胜旧。总览的最终替换仍按 `overview_page_production.md` 第9节比较当前原图与手机图；新页面没有基线时，依据当前内容任务与正例定目标。

## 2. 用真实参考指导画面

实际并排看相关正反图和同系列认可页，再写绘制依据。每张参考分别记录理解收益、审美完成度和本页绘制决定，见 `visual_creation_context.md`。不能把“手绘自然、主次清楚”当作全部观察。

从参考里提取有效做法：同一对象怎样保持可追踪，不同状态怎样显出区别，细节怎样提供比较依据，文字怎样贴近发生处；再根据本页事实重新选择载体与构图。配色、轮廓、两栏或分叉外形不能代替这些解释职责。

明确本页的视觉焦点、可细读局部、正文与图的邻接、主要阅读方向和不同证据的权重。可细读局部应包含本页有用的依据、对应或限定，不用装饰数量衡量。对象细节帮助认物和理解使用关系；文字型区域靠层级、相邻位置、对照和内容关系形成画面。避免先给每段配置一个框，再为每框补图标。

## 3. 先探索结构，再精修载体

先安排承担整页答案的主体，再把证据、案例和边界贴到各自对应处，最后布置辅助导航。每种草图说明主体与支撑的相对位置、空间权重和阅读路径；章节顺序与提纲编号只帮助定位，不预先切出等宽横带。风格参考迁移笔触、身份细节与图文贴合，页面坐标另由本页事实决定。

在现有预检里提出两到三种可执行的视觉策略。新构图与主结构重做先把最有潜力的两个方向画成原生整页草图：用最终正常字级放入全部必留正文、来源边界、标题、导航与页脚，图形轮廓可粗排；实际渲染原图与390px，比较决定性关系、整页焦点、各区域信息分量、疏密转换与阅读路径，选出值得精修的方向。选择记录指出实际占用但没有新增理解收益的部位，以及密集区域如何与其证据邻接；局部核心或文字容量声明不能代替完整摆入。两个方向都只有弱主体加段落时，继续在获准范围内改变表达，不因其中一张更整洁就进入完整精修。草图可以共用系列外围与技术工具，正文组织须有实质区别。探索不等于三个完整候选，也不重置返工计数。已认可页面的限定修订不重做探索。

策略差异可以来自比较对象、观察焦点、证据组织或空间表达。同一准确判断可以有不同优秀构图；不为三案发明三种事实、病因或逻辑机制。SAFE／ADAPTIVE／WILDCARD 只是探索方向，不固定对象。仅换颜色、标题或图标不算实质差异。用户明确要求三种解释机制时，另外保留该约束并核验可行性。

保存构图前预检后，用原生图元构建关键部分和完整内容容量预排，真实导出原图、390px与灰度。重复边框、纸张、对象和连线须各自承担关系；通用载体容纳长段落不会自动变成主图。具象对象先有可信整体，再加关键部位、动作和状态；抽象内容用精确关系与正文级必要文字，不强画物件。

### 具象绘制的事实边界

已批准材料包含真实物件、动作或生活领域时，可以决定可信轮廓、视角、部件与非信息性的造型细节；这些是绘制决定，不必要求转写逐字描述每条轮廓。来源说关系中的回避，可以用一般化人物姿态辅助识别该举例；不能画成某位真实人物的肖像、编入新情节或暗示它由家庭单独导致。来源只给工作阻碍而没有具体阻碍过程时，可以有工作物件身份锚点，不能虚构过程、程度或结果。

图区分的是已批准判断，插画帮助认出具体信息。对象身份细节、姿态与文字贴合应有完成度；不以来源没有描述外观为由把可画内容一律退成文字，也不把示意插画当新增证据。概念无法诚实具象化时，精确关系图仍有效，不强加人物与道具。

也可用明确的视觉隐喻组织已批准概念。预检区分来源事实与表达决定；图中容易被误读为真实过程、计量或结果的部分，须在相邻位置标明示意含义。空间、轨迹或状态只能表达已有关系，不能暗示来源未给的生理机制、数值、先后步骤或因果。若需要补造信息才能让隐喻成立，改用其他载体。

## 4. 核心完成条件

隔离首读者先看真实图与必要文字，读回主要判断、依据和来源限定，再核对内容与参考。绑定当前输入和四类工件，分别记录基本关系可读与 `core_explanation_sufficient`，不判 TARGET。

核心充分性要求：决定性关系被准确表达，图文共同完成本页主要理解任务；证据、例子和解释没有被位置倒造为因果或步骤；主体相对线性段落或未经关系组织的文字，减少可指认的对应、比较、定位或追踪负担；必留内容在正常字级下有可读去向。焦点、空间权重与绘制潜力另在完整构建准备度判断；空间错误已经遮断核心关系或必要内容时，核心仍不充分。

**简单关系可以被充分表达。** 来源只给一个条件判断时，不要求再画一层机制；不把“只有一层”或“没有实物”直接当成拒绝理由。范围、分类或分支不是自动通过：说明它组织了哪些本页具体信息，读者因此怎样得到判断。准确紧凑的关系图仍须检查下面的完整构建准备度，不以核心读懂替代画面潜力。

沿用 `visual_gain_counterproof`：`simple_alternative` 对照同样事实的线性文字或基本段落分组；`remove_subject` 指出移去关系组织后读者要自行完成的工作。替代已经包含相同有效图形组织时，它是另一种好构图，不用“必须超过最优替代”逼出额外装置。没有观察到收益则如实记录，缩小辅助图或改构图。

### 完整构建准备度

相邻比较使用的实际图片须以路径与哈希列入当前审核 `inputs`。本系列首张页面尚无相邻实图时，`series_repetition_check` 如实写明首图范围及暂无相邻图的原因，只用已绑定参考校准，不能声称完成相邻比较。字段非空与哈希检查不能证明实看；审核者确认当前可得范围，不能用泛称“无重复”代替证据。

在核心与准备度之外，单独审查整页构图。先看原图和390px缩略图中的视觉分布，再细读文字；比较草图的主体位置、证据分布、疏密和路径，不能用物件或局部关系不同代替宏观组织不同。与相邻实际页面比较同一组特征，说明重复是否服务当前内容。纵向分段在有内容依据时仍可用；若只是把同一章节骨架填入不同图形，返回结构探索。由内容决定变化，不强制环形、中心式、斜向或每页独特外形。

每案报告另记 `composition_passed`、`composition_evidence` 和 `series_repetition_check`。`composition_evidence` 的四个值须为指认当前实图的非空文本：`main_organization`（主体与支撑的相对位置及权重）、`evidence_placement`（证据和边界如何贴近所支持的判断）、`reading_path`（入口、主线与局部转向提示）、`content_fit`（为何适合本页、为何不只是沿用章节排布）。`series_repetition_check` 写实际相邻图比较与重复理由；单案也核验，不因系列外围一致而免查。构图不成立时，核心关系可以成立，但不放行完整构建；局部绘制尚粗糙不自动否定已适配的组织。

隔离审核者在同一原型报告中另外给出 `full_build_ready` 与 `full_build_readiness_evidence`，只读当前草图、内容和实际参考，不读取作者的期待。三个证据字段值均为非空文本，在其中指认位置与实际依据，分别回答：

- `visual_responsibility`：当前哪个可见局部承担主要判断？它让什么依据或差异直接可比较？装饰人物、放大的标签和通用容器不能代替该职责。
- `composition`：正常字级的完整草图中，主要解释、必要细节和辅助文字的空间分量是否相称？指出细读位置和阅读路径；已有内容足以形成紧凑好图时，不要求扩写或加物件。
- `reference_gap_and_plan`：对照实际正例，哪些质量已可见，哪些仍欠缺？指出在批准事实内可实现的具体精修方向，如状态对照、部件连接、证据邻接或文字轨道。只有换色、调框、加装饰或笼统“画得更精致”的承诺，不足以支持完整精修。

核心充分、整页容量可读、空间与信息职责相称且具有具体完成路径时，才记 `full_build_ready=true`；否则保留已成立的核心关系，定位构图或绘制不足。准备度不是提前签署 TARGET，也不保证最终成功。新增或重新构图的各案都要检查；已认可基线的限定修订沿用范围，不重开该准入。

准备度检查结构能否完成，不要求草图已经精修到 TARGET。局部比例、留白、线条或文字邻接尚需调整时，若当前主结构已有可见依据，能在保留有效组织的基础上完成，可明确记录问题与方向后准入。主焦点没有判断依据、关键对应仍需发明或主体需要重新选择时，先回构图。案例可以承担主表达，其他判断可由必要文字补足；不要求各板块等权、每段都配图或不同内容具有相同视觉复杂度。

支撑区也要根据内容完成图文组织。来源已有具体例子、对象、转向或比较时，须让其归属、区别或变化在画面中可定位；不能把多段连续文章留在支撑区，仅凭主区成立或文字可读承诺能精修到 TARGET。可保留必要解释与限定，不要求每句图解。新增物件须参与识别、比较或证据组织；只在段落旁添图标、把文字拆进多个框、换色或加分隔线，不算解决视觉贫弱。

图形已表达对照、条件或归属，但完成度不足时，失败层记为构图或绘制；来源有重要缺口、当前图造出关系时才记为内容或语义失败。原型放行不包含完整 TARGET、用户批准或发布。

## 5. 完整构建与审美精修

核心充分且完整构建准备度通过后，用 `check_visual_progression.py --stage prototype --case A`（或对应案）核验记录与哈希，再按当前内页/封面合同完整构建，重新保存预检并核对全部内容。原型已粗排全页时可以复用，但完整质量不继承原型放行。

先修最早失败层：判断依据仍靠逐段回读、主体占地却没有相应信息时，调整载体、状态对应和证据组织；关系成立而对象不可信时，修轮廓、连接与动作；局部字号或间距错误时，限定修复。保留准入时成立的视觉职责，针对参考差距落实具体精修，不把原有有效组织换成更大的空载体。新增人物或物件先说明其解释或识别职责，再决定尺度；不能用增加插画掩盖主结构薄弱。

精修实际画面：

- 焦点和节奏：决定性关系醒目、辅助内容有从属；不把等权小标题与段落依次堆放。
- 内容密度：空间用于可比较依据和值得细读的信息，没有空的大载体，不靠微字挤满。
- 绘制完成度：对象有可信轮廓、部件和接触；关系图有准确起止、清楚分岔与舒服的文字轨道。
- 图文协同：说明贴近发生处，边界在需要处可读；图不重复标签，字不替弱图辩护。
- 系列与手机阅读：固定字级、笔触、配色和身份模块，正文构图由内容决定，原图与390px都能阅读。

每次完整图与实际正例比较，指出相近质量与仍有差距的具体部位。完成度比较不要求复制对象或使用更复杂的机制。完整审核的硬错误、解释或审美失败都不由其他优点抵消。

## 6. 三案与返工

解释方法与整页构图分别给结论。三案并排时，除既有方法字段外，另记 `composition_diversity_passed` 和非空文本 `composition_comparison`，指出当前实图在主体／支撑位置、证据组织、空间权重或阅读路径上的实质区别及其内容理由。若只有不同插图装进同一分段骨架，构图探索未完成，即使方法成立也不放行选择。相同主判断可以有不同有效组织，不为差异补造事实；不以布局相似度的自动分数替代实图审查。整页构图、解释收益及绘制完成度各自满足要求，不能互相抵消。

保留逐页三案选择，按 `visual_pack_execution.md` 集中验证最强一案的完整 TARGET，再补另外两案并并排审核策略差异。沿用 `three_methods_passed` 与 `method_evidence` 记录实质视觉策略差异，避免改工具接口；字段名不要求三种不同逻辑真值。

局部问题保留有效关系。全局构图错误才从空白主体重建；准确关系审美贫弱时明确要加强的组织和绘制，不清空一切重做同类容器。返工遵守授权与历史计数。全部为B或更差时，不能用规则文字或作者自评替代完整TARGET。
