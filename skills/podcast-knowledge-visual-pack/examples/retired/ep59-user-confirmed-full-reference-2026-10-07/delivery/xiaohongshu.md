# 《我们都活在指数里》：看看自己的时间怎样被安排

纵横四海 EP59 从“人生ETF”聊起。工作、刷手机和其他娱乐，已经占据了生活的一部分。主讲人建议先看清已有投入，再决定保留什么、调整什么。ETF在这里是生活组合的类比，节目没有给出通用配比。

她用套餐的不同食物解释组合，也讲到在成都停留时间有限时，一次点多杯饮品来分散试错。接下来是更实际的问题：想保留散步、自然、人际和爱好，怎样让它们持续发生？交通成本也在讨论之中。

身心健康部分谈运动、个体身体反应和原生家庭烙印。她建议看过去的影响是否仍妨碍当下生活。相关经历、理论和数字都有核查边界，不能直接当成诊断或效果保证。

AI岗位会怎样变化，节目保留预测的不确定性。她建议当下练习看懂生意各环节的关系。谈阅读时，她追问结论怎样得来，用《稀缺》的架构重组和写日记讲思辨；谈注意力时，则把时间长度与投入分开比较。

现场问答讨论自选流程与自由时间、伴侣间可协商的行动，也谈关系变化，以及宏观意义和微观观察。这些回应来自具体提问和个人经验，适用范围各有边界。
