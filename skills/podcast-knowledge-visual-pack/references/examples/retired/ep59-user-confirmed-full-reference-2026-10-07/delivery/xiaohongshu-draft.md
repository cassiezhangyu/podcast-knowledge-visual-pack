# 《我们都活在指数里》：看看自己的时间怎样被安排

纵横四海 EP59 从“人生ETF”聊起：生活里已有工作、刷手机和其他娱乐投入，也可以主动检视哪些保留、哪些调整。ETF在这里是生活组合的类比，节目没有给出通用配比。

套餐的不同食物、在成都停留有限时一次点多杯饮品，是主讲人说明组合与试错的例子。话题随后落到实际安排：散步、自然、人际和爱好能不能持续，连交通成本也要考虑。

身心健康部分谈到运动、个体身体反应和原生家庭烙印。主讲人建议看过去的影响是否仍在妨碍当下生活；相关经历、理论和数字需要保留核查边界，不能直接当成诊断或效果保证。

AI岗位会怎样变化，节目仍在讨论预测；当下可练的是看懂生意环节之间的关系。阅读部分则追问结论怎样得来，用《稀缺》的架构重组和写日记讲思辨。注意力部分把时间长度与投入分开比较。

现场问答继续讨论自选流程与自由时间、伴侣间可协商的行动、关系变化，以及宏观意义和微观观察。它们保留了具体提问和个人经验，不是统一的人生操作步骤。
