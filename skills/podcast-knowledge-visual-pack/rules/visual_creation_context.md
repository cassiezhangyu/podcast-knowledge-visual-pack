# 逐页创作上下文

本规则处理长会话、连续制作和失败返工时的创作恢复。内容审批与真实图片审核沿用原有门禁；装包、换上下文和执行检查都不产生 完整自检通过。

## 1. 当前会话恢复创作

协调者保留整包状态、用户授权、页号映射、已验收资产和待办。有用户补充验收条件时，以现有生产记录 `user_requirements` 绑定到当前页面合同或传给build_visual_creation_packet.py的 `--user-requirements`；创作前预检inputs保留该文件和当前creation_packet绑定，后续审核自动传递。文件只写用户明确要求及可检查含义，不夹带作者通过结论。

新页面与主结构重做、资料恢复及自检均由当前主会话完成；本任务不调用审核代理。

## 2. 本页输入包

协调者先核验现有内容审批，按 `acceptance_case_index.md` 核对本页必看基准、命中案例与同系列参考，再运行 `scripts/build_visual_creation_packet.py`，传入当前页 ID、内容包、设计 tokens、选定配色和实际正反图片。原页号不同的，显式提供来源页号。脚本绑定当前文件及参考选择规则、检查输入可读并生成中文任务入口；不审批内容、不提炼事实、不设计布局。

需要关键表达试验时，以--creation-stage expression生成当前会话清单，完成难点识别、参考解读、真实试画与作者自检。继续整页时用--creation-stage page更新输入和绑定；不增加审核角色。

创作者先读 `CREATOR_TASK.md` 与 `CREATION_PACKET.json` 并实看绑定图片，按 `visual_reasoning.md` 第1–3节从比较依据选择解释载体，再决定段落、栏位与正常字级整页草图。入口围绕理解任务、可见依据、主体与支撑职责和参考做法组织；本页必留内容按 page_content_planning 的必要性筛选确定，完整来源明细供核实，不是全部上图清单。原型准入按该规则第4节分别核验核心关系与载体完成潜力；完整构建与输出前检查再加载相应实现协议。输入包用于恢复工作，图片质量仍由实际图与作者自检确认。

存在历史页号、导航授权或来源范围变化时，协调者提供 `--page-contract` 绑定的精简当前合同，记录工作页／来源页、工作总页数、导航地图和授权、节目与回听、内容批准记录及未批准补充。由原有门禁核验批准范围；装包不代替批准。缺少影响本页的绑定时，先补交接信息，再完成依赖该信息的模块。原型预检和交接记录另按 `page_visual_production.md` 第3.1节的原型部分执行，不提前加载完整构建检查。

装包前保留本页所选案例的完整来源细节和比较依据供核实；成图只承担当前内容合同选定的必要含义。内容包只有概括句时，协调者核对已批准明细、来源定位及既有认可资产，提供 `--approved-details` 绑定，记录批准范围与出处。原文用于核实，未批准新事实仍走原内容门禁；已验收图中的已批准事实可以恢复，图的旧布局不会因此成为模板。装包仅绑定明细，不自动扩大审批或判定质量。

从空白探索新页时，不携带旧失败图、旧拒绝报告、历史尝试清单、上页构图代码或成品对象函数菜单。用户指定恢复基线或要求比较旧版时，先实际查看指定scene及原图、手机图，连同最新参考和反馈恢复：分别记录已成立的解释职责、当前缺口与验收状态，再按逐页协议第6节确定返工范围。用户认为相对更好不等于正式验收；最新版本也不自动成为工作基线。来源回查和技术实现需要时再加载相关材料并记下用途。渲染器、原生图元 API 和文字测量可复用；正文构图、物件组合与元素坐标服从当前内容与获准修订范围。

## 3. 每页恢复实际审美

协调者在当前页合同中绑定已有相邻页实图及用户最新的风格／构图要求；首图尚无相邻图时记录真实可得范围，按 visual_reasoning 的首图分支执行。主会话读取实际绑定图片，分别检查本页适配与系列重复；参考的绘制品质不携带其正文几何。用户喜欢一案的风格，只有明确选定当前版本才记录为选图，不能推定其排布是后续模板。

当前创作者按 `acceptance_case_index.md` 的“参考选择与解读”，在原尺寸与手机尺度实看图片，将理解收益、画面质量和本页绘制决定写入当前预检。正例指导怎么画，反例排除失败路线；旧观察稿不能代替本页实看。

## 4. 当前工件与输出

按 `visual_reasoning.md` 先做结构探索与真实整页草图。自检确认核心充分性与完整构建准备度后，再按当前合同完整构建；外围模块不能决定正文长成几栏。事实边界与诚实示意的画法统一见该规则第3节，不能自行扩大成对象类别禁用清单。交回scene、三种视图、当前输入绑定、参考观察和内容去向，完成作者自检后输出。

当前主会话对照来源、参考和实际图片完成自检；失败按最早失败层修复。输入变化后重建相关绑定，不继承失效的技术通过。
